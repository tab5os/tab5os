# Tab5 OS API reference (API level 2)

Generated by `tools/abi/apidoc.py` from [`sdk/abi/api_v1.sym`](../sdk/abi/api_v1.sym), the SDK headers and the Python bindings. Do not edit; run `python3 tools/abi/apidoc.py`. The guides are [sdk.md](sdk.md) (C) and [python.md](python.md).

Native apps may call the 413 Tab5 OS functions below, 1908 LVGL 9.6 functions (the LVGL docs apply unchanged) and 223 C library and lwIP functions. **perm** is the manifest permission an app needs: without it the call is bound to a stub that returns `T5_ERR_DENIED`. **tracked** means the OS binds a wrapper that records what the call acquires, so it is freed when the app exits.

- `t5_err_t t5_bt_hci_send(t5_excl_t * h, const void * frame, size_t len);` (perm ble)

Frames are H4: the packet type byte (1 command, 2 ACL, 4 event, 5 ISO) first. The controller is the app's from the claim on (send HCI Reset first); on release the OS resets it and starts its own stack again, with saved pairings intact. If the C6 restarts meanwhile, events stop until it's back.
