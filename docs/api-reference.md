# Tab5 OS API reference (API level 1)

Generated by `tools/abi/apidoc.py` from [`sdk/abi/api_v1.sym`](../sdk/abi/api_v1.sym), the SDK headers and the Python bindings. Do not edit; run `python3 tools/abi/apidoc.py`. The guides are [sdk.md](sdk.md) (C) and [python.md](python.md).

Native apps may call the 295 Tab5 OS functions below, 1907 LVGL 9.6 functions (the LVGL docs apply unchanged) and 223 C library and lwIP functions. **perm** is the manifest permission an app needs: without it the call is bound to a stub that returns `T5_ERR_DENIED`. **tracked** means the OS binds a wrapper that records what the call acquires, so it is freed when the app exits.
